# Anti-Gravity Runner 3.0 🏃💨

A fast-paced, single-file HTML5 arcade runner game where you control gravity!

## 🎮 Play Now
Just open `index.html` in your web browser. No installation required!

## ✨ Features
- **Gravity Flipping**: Use Space or Click to swap gravity.
- **Dash Mechanic**: Use Shift or Right-Click to smash through obstacles.
- **Dynamic Biomes**: The world changes color and theme as you score higher.
- **Procedural Soundtrack**: An infinite Synthwave track generated by code.
- **3 Difficulty Levels**: Cadet, Pilot, and Ace modes.
- **Power-ups**: Shields, Slow Motion, and Score Multipliers.

## 🛠️ Tech Stack
- **Engine**: Custom Vanilla JS Game Loop
- **Rendering**: HTML5 Canvas API
- **Audio**: Web Audio API (Procedural Synthesis)
- **Storage**: LocalStorage for High Scores
